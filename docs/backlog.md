## UI / UX

### 🔴 サービス説明がない
**症状**: 初見ユーザーが「何をするサービスか」「どう使うか」が分からない  
**対処**: ホームのファーストビューに1行キャッチコピー追加（例: 「アニメ・声優・ゲームのイベントを一括チェック」）、または初回訪問時のオンボーディングバナー

### 🔴 ホームのカードにブックマーク☆がない
**症状**: /events のカードには☆ボタンがあるが、ホームのカードにはない。機能が非対称で混乱を招く  
**対処**: ホームの `cardHtml()` にブックマークボタンを追加

### 🔴 タグページにフォローボタンがない
**症状**: `/events?tag=xxx` や `/tags/xxx` でタグ絞り込み中に「このタグをフォロー」ができない  
**対処**: タグイベント一覧ページのヘッダーに「☆ このタグをフォロー」ボタンを追加

### 🟡 関連IPセクション: 非表示化
**経緯**: 汚染データ（中国語IP混入）+ 確度バーの意味不明 + ユーザーが確度を意識すべきか議論の余地  
**対処**: セクションごと削除、またはデータ品質が上がるまで非表示

### 🟡 開催地フィルターがない

### 🟡 日付範囲フィルターがない

---

### 🟡 イベント詳細に関連イベント導線がない

### 🟢 ホームとイベント一覧の差異が伝わらない

## データパイプライン

### 🟡 開催地データが event テーブルに反映されていない
**症状**: `event_source_record.raw_venue_text` には22,235件の会場名・都道府県データがあるが、`event.venue_id` / `event.area_code` が全件NULL  
**原因**: raw_venue_text → venue テーブルへの名寄せ処理が未実装  
**対処**: raw_venue_text をパースして venue upsert + event.venue_id / area_code を埋めるスクリプトを作成・CronJob化  
**効果**: 開催地フィルター・カード上の会場表示が有効になる

---

### 🟡 イベント画像取得スクリプトが未実装
**症状**: `event.hero_image_url` が全件NULL、カードが全て🎪プレースホルダー  
**方針**: 全イベント収集後に別スクリプトで画像URLを取りに行ってDBに入れる  
**対処**: OGP/メタタグから画像URLを取得するスクリプト作成・CronJob化

---

### 🟡 IP汚染: 中国語エントリのフィルタ漏れ
**症状**: 関連IPに `switch缉毒特搜班` 等の中国語コンテンツが表示される  
**原因**:
1. `populate_manami.py` — 日本語title/synonymが皆無なエントリを除外していない
2. `searcher.py` — `instr()` で単語境界なし部分一致のため「スイッチング」→「スイッチ」alias でヒット

**対処**:
- `populate_manami.py` に `if not any(_is_ja(s) for s in [raw_title] + synonyms): continue` を追加
- 既存DBから日本語ゼロのエントリを削除
- `searcher.py` にエイリアス最短長フィルタ or 単語境界チェックを追加

---

### 🟢 start_time/end_time の前向きスクレイピング未対応
**症状**: バックフィル（既存データ）は完了済みだが、新規スクレイプ時に `raw_body` から `開演：HH:MM` を parse していない  
**対処**: `repository.py` の `_parse_datetime()` に start_time/end_time 抽出を組み込む
